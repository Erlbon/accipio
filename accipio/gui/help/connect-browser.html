Connect your browser to Accipio

One step is left, once: add Accipio's extension to Chrome or Edge. Then the downloads you click there come to Accipio. It takes about a minute.

  1. Open the extensions page: copy this address and paste it into the address bar of a new tab. (In Edge it is edge://extensions.)
    chrome://extensions
  2. Switch on Developer mode, the switch at the top right of that page.
  3. Click Load unpacked (top left). In the folder box that opens, paste this folder and choose Select Folder:
    (the extension folder)
  4. Accipio now appears in the list of extensions. Its button in the toolbar (pin it from the puzzle-piece menu) switches the hand-over to Accipio off and on.

If Free Download Manager, Internet Download Manager or another download manager has a browser extension, switch that one off in the same page: both would try to take the same downloads.

Why by hand? Until Accipio is in the Chrome Web Store, Chrome only accepts it this way. Accipio's own window also shows these steps (Tools > Connect Browser).
